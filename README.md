# Multi-touch Attribution

## Overview

This project analyzes customer journeys across multiple marketing touchpoints with two main objectives:

1. Predict whether a customer journey results in a conversion.
2. Attribute conversion value to the marketing channels involved in the customer journey.

The project combines machine learning for conversion prediction with different approaches to multi-touch attribution.

## Objectives

### 1. Conversion Prediction

Develop and evaluate machine learning models to predict whether a customer journey results in a conversion based on the observed marketing touchpoints.

### 2. Marketing Attribution

Analyze the contribution of individual marketing channels to conversions and compare different attribution methodologies.

This project will include heuristic and data-driven attribution approaches.

## Planned Methods

### Conversion Prediction

- Logistic Regression (Baseline)
- Neural Network (RNN)

### Marketing Attribution
- Last-Touch Attribution
- Shapley Values
